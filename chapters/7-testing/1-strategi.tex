\section{Teststrategi}
\label{sec:teststrategi}
Testarbeidet er organisert i tre nivåer: enhetstester for 
isolerte komponenter, integrasjonstester for HTTP-laget, 
og manuell testing mot faktiske testmiljøer. Alle automatiserte 
tester kjøres via GitHub Actions ved push til \texttt{main}, 
\texttt{develop} og feature-brancher, samt ved pull requests.

Testrammeverket er xUnit med Moq for mocking. Eksterne 
tjenester (AntMedia, NHN Video og Keycloak) er fullstendig 
mocket i alle automatiserte tester. Ingen tester krever 
tilgang til faktiske eksterne miljøer.

Målet med testingen var ikke å bevise produksjonsklarhet, men å verifisere at 
proof-of-conceptet oppfyller kravspesifikasjonen og at arkitekturen støtter 
utvidelse med nye videomotorer. Teststrategien hadde derfor fire konkrete mål: 
å verifisere kjerneoperasjonene i krav F1.1--F1.5, å teste sentrale feil- og 
sikkerhetsscenarier, å kontrollere integrasjon mot faktiske AntMedia- og NHN-testmiljøer, 
og å måle hvor mye kjernelogikk som måtte endres ved innføring av nye providere.

\subsection{Reprodusere testresultatene}
\label{subsec:reprodusere-tester}
Testene kan kjøres lokalt med følgende kommandoer:
\begin{lstlisting}[language=bash, caption={Kjøre testsuiten med coverage}]
# Klon repoet
git clone https://github.com/Gruppe-213/HDO-VideoAPI.git
cd HDO-VideoAPI
# Kjør alle tester
dotnet test
# Kjør med coverage-innsamling
dotnet test --collect:"XPlat Code Coverage" \
  --results-directory ./coverage
# Generer lesbar rapport
reportgenerator \
  "-reports:./coverage/**/coverage.cobertura.xml" \
  "-targetdir:./coverage/report" \
  "-reporttypes:TextSummary"
cat ./coverage/report/Summary.txt
\end{lstlisting}
Testene krever .NET~10 SDK. Ingen eksterne tjenester 
er nødvendig — alle avhengigheter er mocket i 
testmiljøet.
