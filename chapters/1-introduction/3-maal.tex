\section{Mål}
\label{sec:maal}

\subsection{Effektmål}
VideoAPI skal forenkle HDOs håndtering av videotjenester ved å tilby ett uniformt \gls{mellomvare}-\gls{api} som abstraherer forskjellene mellom videomotorer. Dette skal gjøre det enklere å integrere nye videomotorer uten at eksisterende klientløsninger må endres, og bidra til å redusere \gls{teknologisk-innlåsing} ved leverandørbytte. Ved å samle kommunikasjonen med videomotorene i ett lag skal løsningen også forenkle drift og overvåking sammenlignet med å forholde seg til hver motor separat. Effektmålene er kvalitative og kan først verifiseres gjennom faktisk produksjonssetting og videre integrasjon hos HDO.

\subsection{Resultatmål}
Prosjektet skal resultere i følgende leveranser:
\begin{enumerate}
  \item Et \gls{rest-api} med plugin-arkitektur og \gls{oauth2}/\gls{jwt}-autentisering.
  \item Helsesjekker, strukturert logging og Prometheus-monitorering.
  \item \Glspl{provider-adapter} for AntMedia Server og NHN Video.
  \item En enkel \gls{demo-frontend} for å demonstrere API-et i praksis.
  \item OpenAPI/Swagger-dokumentasjon beregnet på eksterne leverandører.
  \item README, deployment-guide og utviklerdokumentasjon for videre arbeid.
  \item En containerisert løsning med Docker og \gls{cicd} via GitHub Actions.
\end{enumerate}

\subsection{Læringsmål}

Ettersom gruppen ikke har tidligere erfaring med C\# eller .NET, vil de første sprintene benyttes til å tilegne seg språket og økosystemet parallelt med utvikling. Gjennom prosjektet skal gruppen opparbeide praktisk erfaring med .NET 10, ASP.NET Core, REST-API-design, plugin-arkitektur, Docker, GitHub Actions og Prometheus/Grafana.

Samarbeidet med HDO som ekstern oppdragsgiver skal i tillegg gi erfaring av mer prosjektfaglig karakter: kravhåndtering, tekniske avklaringer og arbeid under leveransekrav i et reelt prosjekt.
