\section{Authentication}
\label{sec:impl-auth}

Backenden bruker Keycloak som ekstern identitetsleverandør for autentisering, basert på OAuth2 client-credentials-flow. Selve tokenet genereres ikke av applikasjonen, men hentes fra Keycloak og valideres av ASP.NET Cores innebygde JWT Bearer-middleware.

\subsection{Token-flyt}

Klienter autentiserer seg ved å sende en \texttt{POST}-forespørsel til \texttt{/auth/token}, der \texttt{clientId} og \texttt{clientSecret} inkluderes i request-bodyen. \texttt{AuthController} videresender forespørselen til \texttt{KeycloakService}, som kaller Keycloaks token-endepunkt med \texttt{client\_credentials}-grant og returnerer \texttt{access\_token} til klienten (jf. kodeliste~\ref{lst:auth-controller}--\ref{lst:keycloak-service}). Systemet lagrer ingen rom- eller sesjonsdata server-side. \texttt{NHNTokenCache} mellomlagrer NHN-tokenet prosessinternt, men ingen videoromtilstand persisteres mellom forespørsler.

\begin{lstlisting}[language={[Sharp]C}, label=lst:auth-controller, caption={\texttt{AuthController.cs} – token-endepunkt}]
// HDO-VideoAPI/Controllers/AuthController.cs

[ApiController]
[Route("auth")]
public class AuthController(IKeycloakService keycloakService) : ControllerBase
{
    // Åpent endepunkt
    [AllowAnonymous]
    [EnableRateLimiting("auth")]
    [HttpPost("token")]
    public async Task<IActionResult> GetToken([FromBody] TokenRequest request)
    {
        // Deleger til Keycloak Service og returner access_token
        var token = await keycloakService.GetTokenAsync(request.ClientId, request.ClientSecret);
        return Ok(new { access_token = token });
    }
}
\end{lstlisting}

\begin{lstlisting}[language={[Sharp]C}, label=lst:keycloak-service, caption={\texttt{KeycloakService.cs} – kall mot Keycloak}]
// HDO-VideoAPI/Services/KeycloakService.cs

public async Task<string> GetTokenAsync(string clientId, string clientSecret)
{
    // Bygg client_credentials-forespørsel (machine-to-machine auth)
    var formData = new Dictionary<string, string>
    {
        ["grant_type"] = "client_credentials",
        ["client_id"] = clientId,
        ["client_secret"] = clientSecret
    };

    // Send til Keycloak token-endepunkt
    var response = await httpClient.PostAsync(
        $"{_config.BaseUrl}/realms/{_config.Realm}/protocol/openid-connect/token", 
        new FormUrlEncodedContent(formData));

    // ... (feilhåndtering og logging)

    // Ekstraher og returner access_token
    var json = await response.Content.ReadFromJsonAsync<JsonElement>();

}

\subsection{Tilgangskontroll}

Autorisasjonspolicyen er flat, uten rollebasert tilgangsstyring. Alle klienter med et gyldig token og korrekt claim har identiske rettigheter. Et gyldig token uten \texttt{api\_access = true} resulterer i \texttt{403 Forbidden}, mens manglende eller ugyldig token gir \texttt{401 Unauthorized} (jf.\ kodeliste~\ref{lst:keycloak-extensions}).

\begin{lstlisting}[language={[Sharp]C}, label=lst:keycloak-extensions, caption={\texttt{KeycloakExtensions.cs} – JWT-validering og autorisasjonspolicy}]
// HDO-VideoAPI/Extensions/KeycloakExtensions.cs

public static IServiceCollection AddVideoKeycloak( ... )
{
    // ... (konfigurasjon)
    
    // Konfigurer JWT-validering mot Keycloak
    services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
        .AddJwtBearer(options =>
        {
            var baseUrl = configuration["Keycloak:BaseUrl"];
            var realm = configuration["Keycloak:Realm"];
            options.Authority = $"{baseUrl}/realms/{realm}";
            options.RequireHttpsMetadata = false;   // false kun for internt testmiljø
            options.TokenValidationParameters = new()
            {
                ValidateAudience = false,           // false kun for internt testmiljø
                ValidateIssuer = false              // false kun for internt testmiljø
            };
        });
    
    // Krev gyldig token med api_access-claim på alle beskyttede endepunkter
    services.AddAuthorization(options =>
    {
        options.DefaultPolicy = new AuthorizationPolicyBuilder()
            .RequireAuthenticatedUser()
            .RequireClaim("api_access", "true")
            .Build();
    });

    // Returnerer builder for method chaining
    return services;
}
\end{lstlisting}
